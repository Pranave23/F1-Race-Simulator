# Frontend Application

The **frontend** folder contains a React‑based web UI for the F1 Race Simulator. It provides:

- **Race selection UI** – browse historical races and choose one to reconstruct.
- **Strategy editor** – interactive controls to tweak tyre compounds, fuel loads, pit‑stop windows, and other tactical parameters.
- **Results dashboard** – visualizes lap‑by‑lap performance, probability distributions from the Monte Carlo engine, and displays the plain‑language explanation generated by the LLM.
- **Responsive design** – works on desktop browsers; mobile support can be added later.

The UI communicates with the backend via a REST API (hosted at `http://localhost:8000`). Development is powered by `npm`/`yarn` and uses standard React libraries (React Router, Redux Toolkit, Material‑UI).
