# Model Package

The **models** subpackage contains the trained machine‑learning artefacts used by the degradation engine. It includes:

- **tyre_degradation.pkl** – model predicting tyre wear and performance loss per lap based on historical telemetry and environmental factors.
- **fuel_consumption.pkl** – regression model estimating fuel usage across lap distance.
- **metadata.json** – details about training data, feature definitions, versioning, and evaluation metrics.

Utility functions are provided to load these artefacts safely:

```python
from . import load_model
model = load_model('tyre_degradation.pkl')
```

The package is designed to be lightweight and serialisable, allowing the backend to cache the models in memory for fast inference during Monte Carlo runs.
