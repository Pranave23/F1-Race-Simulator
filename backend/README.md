# Backend Overview

This directory contains the **FastAPI** backend service for the F1 Race Simulator. It exposes a REST API that:

- Accepts race selections and user‑defined strategy changes (tyre choice, fuel load, pit‑stop timing).
- Retrieves historical telemetry data and race context.
- Calls the ML simulation library to run the degradation model combined with a Monte Carlo engine.
- Returns lap‑by‑lap results, uncertainty metrics, and a plain‑language explanation generated by an LLM.

The backend orchestrates the flow between the frontend, the ML simulation package (`backend/ml_simulation/`), and any external model artefacts. It is containerised and runs on port **8000**.
